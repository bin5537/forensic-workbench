# Forensic Workbench

디지털 포렌식 워크벤치 — 데스크톱 앱(Electron + React). 삭제된 파일·사진 복구, PC 디지털 발자국 분석,
모바일(안드로이드/아이폰 백업)·PC 분석, 케이스 관리와 증거 무결성까지 한 화면에서.

> 본인이 소유했거나 문서화된 권한이 있는 기기·데이터의 분석을 위한 도구입니다. 각 케이스에 권한 근거를 기록하세요.

## 주요 기능

- **PC 분석 · 디지털 발자국** — 브라우저 기록을 분석해 다운로드(삭제된 파일 포함)·방문 사이트·검색어·최근 연 파일을 정리
- **삭제된 파일 복구** — 휴지통 복구, 캐시(썸네일·브라우저·메신저) 기반 사진 자동 탐색, 디스크 이미지 시그니처 카빙
- **이전 버전에서 복구** — Windows 복원 지점(볼륨 섀도 복사본)에서 예전 파일을 이름 그대로 복원 *(관리자 권한)*
- **안드로이드** — ADB 연동: 기기 정보·앱·통화/SMS/연락처·logcat·스크린샷·논리적 수집
- **아이폰 백업** — 비암호화 백업 파싱(메시지·연락처·통화)
- **PC / 디스크** — 파일 탐색·해시(SHA-256/MD5)·MACB 타임라인·빠른 스캔
- **케이스 · 보고서** — 증거 무결성 지문화·재검증·연계 보관성 로그·HTML 보고서

## 개발

```bash
npm install
npm run dev      # Vite + Electron (HMR)
```

프로덕션 실행:

```bash
npm run build && npm start
```

## 배포용 빌드 (Windows 설치 파일)

```bash
npm run dist     # release/ 에 설치 파일 생성
```

## 참고

- 셸 환경에 `ELECTRON_RUN_AS_NODE=1`이 설정돼 있으면 Electron이 순수 Node로 실행되어
  `whenReady` 오류가 납니다. `scripts/launch.js`가 실행 전 해당 변수를 제거하므로
  `npm run dev` / `npm start`는 자동으로 처리됩니다.
- 이전 버전 복구는 관리자 권한이 필요하며, 앱 안에서 "관리자 권한으로 다시 실행"으로 승격할 수 있습니다.
